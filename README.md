# score-stats

一个极简的成绩统计小工具，用于《程序设计实践》小作业1
「基于 Git 的团队协作工作流实践」的演示。

## 功能

| 函数 | 说明 |
| --- | --- |
| `total(scores)` | 总分 |
| `average(scores)` | 平均分 |
| `highest(scores)` | 最高分 |

## 运行

```bash
python stats.py
```

## 测试

```bash
python -m unittest -v
```

## 目录结构

```
stats.py        统计函数
test_stats.py   单元测试
```
